# API 接口文档

## 通用规范

- 成功响应 (HTTP 200): 直接返回业务数据，无包装
- 错误响应 (HTTP 4xx/5xx): 用户侧接口与 WebSocket 使用错误码规范，管理端接口使用 detail/request_id 规范（登录前请求按隐藏错误规则），详见 [错误码规范](error-codes.md)
- 时间格式规范见 [时间格式规范](docs\spec\time-format.md)，所有接口涉及时间字段均遵循此规范。

### 拟人化设计

**本项目是AI拟人陪聊应用，核心目标是让用户相信这是真人交互。**

1. **避免暴露AI**：接口中不应该出现 "contact_type" 这些区分真人和AI的字段, 这些字段仅服务于后端
2. **隐藏技术细节**：与前端无关的后台逻辑, 例如 ai_types_id 等不应出现在API中
3. **尽量隐藏第三方**：API路径中尽量不包含第三方服务名称（如LeanCloud、Aliyun等）


### 枚举值管理原则

**单一数据源**：

- 所有枚举值定义在 `backend/app/enums/common.py` 中
- 数据库文档（`docs/data-dict/*.md`）作为枚举值的参考说明
- API 文档不硬编码枚举值，统一引用 `backend/app/enums/common.py`

### 速率限制

**短信验证码**:

- 速率限制：1次/60秒（同一号码）
- 白名单：支持配置白名单号码（不受限制）

**用户认证**:

- 速率限制：10次/小时
- 失败次数限制：5次失败后锁定
- 锁定时长：15分钟
- 人机验证触发：3次失败后需要人机验证

**消息发送**:

- 短期限制：5条/10秒
- 长期限制：20条/分钟

**通用API**:

- 通用限制：100次请求/分钟/IP
- 白名单：支持配置白名单IP（不受限制）
