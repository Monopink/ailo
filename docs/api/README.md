# API 接口文档

## 通用规范

- 成功响应 (HTTP 200): 直接返回业务数据，无包装
- 错误响应 (HTTP 4xx/5xx): 用户侧接口与 WebSocket 使用错误码规范，管理端接口使用 detail/request_id 规范（登录前请求按隐藏错误规则），详见 [错误码规范](error-codes.md)
- 时间格式规范见 [时间格式规范](../spec/time-format.md)，所有接口涉及时间字段均遵循此规范。
- API路径中尽量不包含第三方服务名称（如LeanCloud、Aliyun等）
- API 文档不硬编码枚举值，统一引用 `backend/app/enums/`

### 速率限制

- 接口可能受到业务限流与全局 IP 限流保护；超限可返回 `429`（包含 `Retry-After` 响应头）。登录前/风控类请求可能以保护性拒绝形式返回 `400`。
- 具体阈值由服务端配置管理，客户端不得写死。
