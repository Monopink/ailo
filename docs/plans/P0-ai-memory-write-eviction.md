# AI 记忆：写入超额归档（memory_limits）

## 目标

- 当记忆写入导致数量超过 `memory_limits` 时，在写入阶段执行归档（而不是仅在检索阶段裁剪）。

## 现状

- `memory_limits` 当前仅用于检索阶段的数量裁剪。
- 写入阶段不会因为超额而拒绝或归档记录。

## 待实现

- 写入阶段对 core/recent 分别执行数量上限控制：
  - 超额时将超出部分按规则归档（`status=2`）。
  - 归档顺序与检索排序规则需要一致（避免归档“更重要”的记忆）。
- 在写入链路中明确“上限与归档”的一致性约束，并补充监控指标（归档数量、触发频率）。
