# 媒体上传：内容审核

## 目标

- 在媒体文件上传后、可访问 URL 返回前，完成内容审核（NSFW/违法内容等），避免非法内容传播。

## 现状

- 上传链路没有内容审核步骤。

## 待实现

- 引入内容审核服务并接入上传链路：
  - 审核通过：返回 URL
  - 审核失败：拒绝并将文件标记为删除/不可访问
  - 审核超时/异常：按明确规则处理（需要定义一致的用户侧反馈）
- 记录审核结果与追踪信息，便于审计与误杀复核。
