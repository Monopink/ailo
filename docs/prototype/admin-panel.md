# 管理端（网页）原型文档

## 权限说明

- super_admin: 可以管理其他管理员，拥有所有权限
- admin: 有修改权限，可以管理业务数据
- viewer: 只有查看权限，无法修改数据

## 页面设计

### 登录页

简单的用户名密码登录，记录登录日志。

### 仪表盘

显示系统关键指标的概览页面。

#### 核心数据卡片

- 用户统计: 总用户数、今日新增用户、活跃用户数（日/周/月）
- 消息统计: 消息总数、今日消息数、平均每用户消息数
- AI统计: AI请求总数、今日AI请求数、启用的ai_profile_templates数量
- 收入统计: 总收入、本月收入（未来功能）
- 订阅统计: 订阅用户数、本月新增订阅、本月退订（未来功能）

#### 趋势图表

- 用户增长趋势（近30天）
- 消息量趋势（近30天）
- AI请求量趋势（近30天）

### 用户管理

包含users表、profiles表数据的综合管理。

#### 用户列表

- 显示用户基本信息：qiao_id、username、phone、status、创建时间
- 支持按状态、创建时间筛选
- 支持用户名、手机号搜索

#### 用户详情页

- 基本信息: 用户账户信息、资料信息
- 登录记录: 显示login_records表数据
- 联系人: 显示contacts表数据，用户的AI联系人列表
- 会话记录: 显示user_sessions表数据
- 订阅信息: （未来功能）
- 交易记录: （未来功能）

### 会话管理

管理用户登录会话，基于user_sessions表。

#### 功能列表

- 在线用户列表: 显示当前活跃的用户会话
- 会话详情: 设备类型、IP地址、登录时间、最后活动时间
- 强制下线: 踢出指定用户（设置session为inactive）
- 异常检测: 标记异常IP、超长会话等
- 统计信息: 各平台用户分布、平均会话时长

### 消息管理

基于message_history和message_delivery_failures表的消息系统管理。

#### 消息历史

- 消息列表: 显示所有消息记录，支持按对话、用户、时间筛选
- 消息详情: 显示完整的消息内容和元数据
- 消息统计: 按时间段、用户、AI角色的消息量统计

#### 投递失败管理

- 失败列表: 显示message_delivery_failures表数据
- 重试操作: 手动触发消息重发
- 失败分析: 按失败原因统计，帮助排查问题

#### 查看对话

将消息按照对话显示（类似聊天界面），并且可以代替AI回复消息。（2.0功能，暂时不开发）

### AI管理

基于AI相关数据表的综合管理模块。

#### ai_characters（AI角色管理）

- 角色列表: 显示所有AI角色，支持按用户、状态筛选
- 对话测试：对指定AI角色发起。选定用户和模型配置后可以进行对话测试。
- 角色详情: 查看角色配置、关联的风格和人格
- 查看分数: 显示ai_relationship_score表数据
- 查看上下文: 显示ai_contexts表数据，AI对话历史
- 发送联系人申请: 管理员可以为无归属的AI角色向用户发送好友申请（2.0功能）
- 新增角色: 管理员可以创建新的AI角色（2.0功能）

##### 对话测试

作为AI角色的功能按钮，独立页面打开。

表单：

1. LLM Configuration（下拉菜单，包含所有可用的llm_configs）
2. 输入框：测试消息内容

不应该包含的表单：

1. AI角色选择（AI角色固定为当前角色）
2. 用户选择（每个AI角色最多只能有一个测试用户）

不能开始测试的情况：

1. AI角色缺少Profile
2. AI角色没有关联测试用户（type:vitual）或关联的不是测试用户
3. 测试用户没有Profile
4. 占位符验证出错误、Json Schema出错等验证问题

输出内容：

1. 对话记录
2. 请求记录（更新在request_logs表）

#### ai_personalities（AI人格管理）

- 人格列表: 显示所有AI人格模板
- 人格编辑: 编辑提示词模板和JSON schema
- 占位符管理: 管理ai_personality_placeholders表，编辑提示词时检查占位符完整性
- 使用统计: 显示usage_count，被引用的数量

#### ai_styles（AI风格管理）

- 风格列表: 显示所有AI风格
- 风格配置: 管理评分维度和评分名称
- 关系管理: 专门页面管理ai_relationship_indexes，在分数轴上直观显示关系位置
- 使用统计: 显示usage_count统计

##### 分数算法测试

表单：

1. 算法选择（下拉菜单，写死的算法列表）
2. 偏移参数
3. 当前关系
4. 分数值Score*N（模拟LLM输出的分数，对应N个维度）
5. 最大分数值Score max*N（分数值的终点，用于计算position映射，对应N个维度）
6. 最小分数值Score min*N（分数值的起点，用于计算position映射，对应N个维度）

输出内容：

1. dimension_name
2. 没有经过算法偏移直接映射的position
3. 偏移后的positon
4. ai_relationship.display_name
5. ai_relationship.prompt_fragment

注：测试时忽略ai_relationship_indexes.limit_count的影响

#### ai_relationship（AI关系管理）

- 关系类型列表: 显示所有关系类型
- 关系编辑: 编辑关系名称和提示词片段
- 使用统计: 显示usage_count，被引用数量

#### ai_info_templates（AI信息模板管理）

- 模板列表: 显示所有信息模板

- 关联风格: 关联ai_styles表数据

#### ai_profile_templates（AI社交模板管理）

- 模板列表: 显示所有社交资料模板
- 模板编辑: 编辑昵称、性别、头像、简介等信息

- 复用设置: 管理is_reusable字段，控制模板复用

#### ai_request_logs（AI请求记录）

- 请求列表: 显示所有AI请求日志
- 请求详情: 查看请求内容、响应内容、状态
- 性能统计: 响应时间、成功率、token消耗统计
- 错误分析: 按失败原因分类统计

### LLM 管理

#### 设计说明

- 同一个 Provider（如 doubao）可以有多个配置记录，通过 `display_name` 区分
- 例如：可以创建 "Doubao Production"、"Doubao Test"、"Doubao Backup" 等多个配置
- `name` 字段用于代码层面的 SDK 选择，`display_name` 用于 UI 显示和唯一标识

json_schema_mode 说明：

- 自动更新：此字段会在配置测试时根据实际响应格式自动更新
- 使用限制：AI Character功能只能使用 `json_schema_mode='strict'` 的配置
- 测试流程：
  1. 新配置默认为 `'auto'`（未验证）
  2. 在配置测试页面进行测试
  3. 系统检测响应格式：
     - 如果返回JSON → 自动更新为 `'strict'`
     - 如果返回普通文本 → 自动更新为 `'disabled'`
  4. 测试结果会显示完整响应内容和JSON Schema支持状态
- 运行时保护：
  - 使用 `'auto'` 配置会提示"未验证，请先测试"
  - 使用 `'disabled'` 配置会提示"不支持JSON Schema，无法使用"
  - 如果 `'strict'` 配置返回非JSON，会自动更新为 `'disabled'` 并报错

API Key 管理：

- API Key 不存储在数据库中，而是存储在环境变量中
- `api_key_env` 字段指定环境变量名（如 `DOUBAO_PROD_API_KEY`）
- 如果 `api_key_env` 为空，则使用默认命名规则：`{NAME}_API_KEY`（如 `DOUBAO_API_KEY`）
- 这种设计既保证了安全性，又提供了灵活性

### 媒体文件管理

基于media_files表的文件管理功能。

#### 文件管理

- 文件列表: 显示所有媒体文件，支持按类型（头像/图片/表情）筛选
- 文件详情: 显示文件信息、上传者、大小、URL等
- 文件操作: 查看、删除文件（谨慎操作）
- 批量管理: 批量删除、按条件筛选

#### 存储统计

- 空间使用: 总存储空间、各类型文件占用统计
- 上传统计: 按时间、用户的上传量统计
- 异常监控: 检测异常大文件、违规内容

#### emoticons（表情管理）

- 表情列表: 显示所有表情，支持按分类筛选
- 表情编辑: 编辑表情描述、分类、排序
- 表情上传: 上传新的系统表情
- 使用统计: 表情使用频率统计

### 联系人申请管理

基于contact_requests表的申请管理。

#### 申请列表

- 待处理申请: 显示所有联系人申请
- 申请详情: 显示申请者、接收者、申请消息、来源等
- 批量操作: 批量通过或拒绝申请（如需要）

### 统计报表

基于各种stats表的数据分析。

#### 用户统计

- 用户增长: 基于stats_user_daily/weekly/monthly表
- 活跃度分析: 新增用户、活跃用户趋势
- 用户行为: 平均使用时长、功能使用情况

#### 消息统计

- 消息量分析: 基于stats_message_daily/weekly/monthly表
- 对话活跃度: 活跃对话数、平均消息数
- 消息类型分布: 文本、图片、表情等类型统计

#### AI统计

- AI使用情况: 基于stats_ai_daily/weekly/monthly表
- 请求量分析: AI请求数、成功率、响应时间
- 热门AI: 最受欢迎的AI角色和模板

#### 收入统计（未来功能）

- 收入趋势: 基于stats_revenue_daily/weekly/monthly表
- 订单分析: 订单量、平均订单金额
- 用户价值: 付费用户分析、ARPU等

### system_configs（系统配置）

系统参数配置管理。

#### 配置管理

- 配置列表: 显示所有系统配置项
- 配置编辑: 修改配置值，支持不同数据类型
- 配置分类: 按功能模块分类显示
- 配置历史: 记录配置变更历史

### 系统管理

#### admin_users（管理员用户管理）

- 管理员列表: 显示所有管理员账户（仅super_admin可见）
- 权限管理: 管理admin、viewer权限
- 账户操作: 新增、禁用管理员账户
- 登录统计: 显示管理员登录情况

#### admin_operation_logs（管理员操作日志）

- 操作记录: 显示所有管理员操作日志
- 日志筛选: 按管理员、操作类型、时间筛选
- 操作统计: 各类操作的频率统计
- 安全审计: 异常操作检测和分析

#### admin_login_logs（管理员登录日志）

- 登录记录: 显示所有管理员登录历史
- 安全监控: 异常IP、失败登录检测
- 登录统计: 登录频率、时间分布分析

### 安全监控

基于user_security_logs和user_security_stats表的用户安全管理。

#### 实时安全监控

- 安全概览: 今日违规统计、高风险用户数量、待审核事件数
- 实时告警: 严重违规行为实时提醒
- 风险趋势: 违规行为趋势图表，按类型和严重程度分析

#### user_security_logs（违规记录管理）

- 违规列表: 显示所有用户违规记录，支持按用户、类型、严重程度筛选
- 记录详情: 查看原始消息、AI检测结果、置信度分数
- 人工审核: 对AI检测结果进行人工确认或标记为误报
- 批量处理: 批量审核相似违规记录

#### user_security_stats（用户风险评估）

- 高风险用户: 显示当前风险等级为high/banned的用户列表
- 用户风险详情: 查看用户完整的违规历史和统计数据
- 风险等级调整: 手动调整用户风险等级
- 处理历史: 查看对用户采取的所有处理措施

#### 自动处理规则配置

- 规则设置: 配置不同违规类型和严重程度的自动处理策略
- 阈值管理: 设置触发警告、限制、停用的违规次数阈值
- 白名单管理: 管理免检用户白名单（如测试账户）

#### 安全统计分析

- 违规趋势: 按时间、类型、严重程度的违规统计
- 用户行为分析: 违规用户的行为模式分析
- 检测效果评估: AI检测准确率、误报率统计
- 处理效果跟踪: 各种处理措施的效果评估
