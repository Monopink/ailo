# 仪表盘规范

仪表盘用于展示管理端首页核心状态与趋势。

## 核心数据卡片

- 用户统计：总用户数、今日新增用户、活跃用户数（日/周/月）
- 消息统计：消息总数、今日消息数、平均每用户消息数
- AI 统计：AI 请求总数、今日 AI 请求数、启用的 `ai_personas` 数量

## 趋势图表

- 用户增长趋势（近 30 天）
- 消息量趋势（近 30 天）
- AI 请求量趋势（近 30 天）

## 系统状态卡片

### LeanCloud 服务状态

- 可达：绿色图标 + 文案“可达”
- 不可达：红色图标 + 文案“不可达” + 错误信息
- 操作：`[刷新]` 按钮

### 系统对话状态

- 已创建：绿色图标 + 文案“已创建” + 对话 ID
- 未创建：黄色图标 + 文案“未创建”
- 无效：红色图标 + 文案“无效” + 错误信息
- 操作：`[刷新]` 按钮

### 最后检查时间

- 展示最近一次状态检查时间

## 口径一致性要求

- 仪表盘与系统设置页中的系统状态卡片必须使用相同状态定义与文案
- 同一指标在不同页面的统计口径必须一致，不允许页面自定义口径
