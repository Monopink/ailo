# 统计报表规范

统计报表页基于各类 `stats_*` 数据表提供趋势分析与业务洞察。

## 用户统计

- 用户增长：基于 `stats_user_daily/weekly/monthly`
- 活跃度分析：新增用户、活跃用户趋势
- 用户行为：平均使用时长、功能使用情况

## 消息统计

- 消息量分析：基于 `stats_message_daily/weekly/monthly`
- 对话活跃度：活跃对话数、平均消息数
- 消息类型分布：文本、图片、表情等

## AI 统计

- AI 使用情况：基于 `stats_ai_daily/weekly/monthly`
- 请求量分析：AI 请求数、成功率、响应时间
- 热门 AI：最受欢迎的 AI 实例和模板

## 收入统计（未来功能）

- 收入趋势：基于 `stats_revenue_daily/weekly/monthly`
- 订单分析：订单量、平均订单金额
- 用户价值：付费用户分析、ARPU
