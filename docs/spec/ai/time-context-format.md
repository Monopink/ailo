# 时间上下文格式规范

## 适用范围

用于 system placeholder `{{current_datetime}}` 的文本生成。

## 主行格式

```
{公历日期} {农历日期}（{生肖}年）星期{X} 今天{日类型与事件串} {时段}{12小时制时间}（{24小时制时间}）
```

## 周视图格式

```
过去一周：{日期A}（{相对词A}）{事件A}、{日期B}（{相对词B}）{事件B}
未来一周：{日期C}（{相对词C}）{事件C}、{日期D}（{相对词D}）{事件D}
```

无事件时输出：

```
过去一周：无
未来一周：无
```

## 字段定义

### 公历日期

格式：`YYYY年M月D日`

### 农历日期

格式：`{干支年}{农历月}{农历日}`

示例：`丙午年二月初一`

### 生肖

格式：`{生肖}年`

示例：`马年`

### 星期

格式：`星期一` 到 `星期日`

### 日类型与事件串

基础日类型取值：

- `工作日`
- `周末`
- `法定假`
- `调休`

事件串按以下顺序拼接，分隔符为 `、`：

1. 法定安排（`法定假` 或 `调休`，与基础日类型一致时不重复）
2. 节气
3. 节日（可多值）
4. 假期剩余（格式：`{节日名}（假期还有N天）`）

### 时段与时间

- 12小时制时间格式：`h:mm`
- 24小时制时间格式：`HH:mm`
- 时段映射：
  - `00:00-05:59`：`凌晨`
  - `06:00-08:59`：`早上`
  - `09:00-11:29`：`上午`
  - `11:30-12:59`：`中午`
  - `13:00-17:59`：`下午`
  - `18:00-18:59`：`傍晚`
  - `19:00-23:59`：`晚上`

## 相对词规则

过去一周相对词：

- `1天前`：`昨天`
- `2天前`：`前天`
- `3-7天前`：`{N}天前`

未来一周相对词：

- `1天后`：`明天`
- `2天后`：`后天`
- `3-7天后`：`{N}天后`

## 数据来源与职责

### pendulum

- 当前时间
- 时区转换
- 星期
- 相对日期计算
- 12/24 小时制格式化

时区来源：`instance.timezone`（IANA 时区标识）

### lunar_python

- 农历年月日
- 干支
- 生肖
- 节气
- 农历节日与公历节日

### chinese-calendar

- 法定节假日
- 调休
- 工作日判断

法定安排数据范围：`2004-2026`

## 错误处理

时间合成过程中任一子部分失败时：

- 记录错误日志
- 对应子部分输出空内容
- 不输出说明性兜底文案
