# App原型文档

## 页面

### 登录页

### 主界面底部导航栏

【聊天】主界面默认页面，点击进入聊天页。

【发现】点击进入发现页。

【我的】点击进入我的页。

### 聊天

#### 顶栏

【信息区域】默认情况为「敲敲(3)」显示品牌名（来自环境变量），括号展示未读消息数量，最高为99+，如果为0则不显示。

网络、服务异常时显示「正在连接…」。

加载内容时显示「正在加载…」。

#### 聊天列表

聊天列表按照最后消息的日期顺序排列。置顶的的聊天显示在最前，并且按照日期顺序排列。

点击聊天列表进入聊天页面，右滑聊天列表出现右滑菜单。

【搜索栏】下滑出现在顶部，点击进入搜索页。

【头像】未来支持使用图片，目前使用昵称首字符+字符对应特定颜色算法生成背景颜色作为头像，如果昵称为空则使用「？」。

【名称】备注或nickname，备注优先。如果为空则显示空白，不要设置默认值。

【日期】最近的一条消息的日期。

【最近的一条消息缩略】不包括CHAT_INFO或输入状态消息。

【标签】显示在名称右侧，标签形式。

【消息圆点/消息数量红点】根据「消息免打扰」设置决定显示圆点还是消息数量。

【右滑聊天】点击进入聊天界面，右滑选项：标为未读、删除。点击标为未读可以增加消息圆点。点击删除选项扩大文字变为：确认删除。点击确认删除删除聊天记录并将聊天从聊天列表移除。

### 发现

顶栏内容：发现。

【寻找好友】点击进入对应页面。

### 我的

【个人资料缩略】头像、昵称。点击进入个人资料页。

【会员等级】点击进入会员页面。

【通讯录】点击进入通讯录页。

【收藏】点击进入收藏页。

【设置】点击进入设置页。

### 搜索

可以搜索聊天记录和联系人信息（nickname、备注、标签）

### 对话页面

#### 顶栏

【<】后退按钮。

【信息区域】正常情况备注或nickname，备注优先。如果为空则显示空白，不要设置默认值。

当输入状态显示「对方正在输入…」

【…】更多按钮。点击进入聊天详情页面。

#### 聊天区域

【日期】小号字体，水平居中。

【chat_info消息】样式和日期一致。

【对方头像和气泡】气泡为无颜色灰度和背景区分。

【自己的头像和气泡】气泡为绿色（产品主色调）。

#### 输入区域

【表情按钮】点击出现表情选择，表情选择框对表情进行分组展示。

表情包括emoji字符、自定义emoji。点击emoji分组的表情加入到输入框。

【输入框】输入框从空白输入内容后（包括输入法的开始输入状态）发送开始输入的状态，输入框从有内容删除所有内容（且输入法的没有输入状态）发送结束输入状态。输入框字符上限收到最大上限限制，由环境变量控制。

【发送按钮】点击发送内容。
