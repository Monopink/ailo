# 联系人与聊天

本规范定义联系人列表、对话页面与聊天设置的通用行为。

## 联系人列表（聊天列表）

### 数据来源

- [联系人列表接口](../../../api/contacts.md#获取联系人列表)

### 排序规则

- 一级排序：最后消息时间倒序
- 最后消息时间取值优先级：会话本地时间线中最新可渲染消息的 `sent_time`，其次 `last_message_time`
- 二级排序：`conversation_id` 升序（用于同时间稳定排序）
- 无可用消息时间的会话位于列表末尾

### 列表项展示

- 头像：显示联系人头像（如未设置则由后端返回默认头像）
- 名称：备注优先，否则昵称；为空则保持空白
- 日期：最近一条消息时间，显示在第一行右侧
- 内容区：固定三行排版，不因标签或最近消息缺失而改变高度
- 第一行：名称（左）+ 日期（右）
- 第二行（有标签）：标签胶囊，仅展示单行容量内的完整标签
- 标签颜色：按标签文本归一化（trim + 小写）后哈希映射到固定色盘，同名标签跨页面保持同色
- 溢出标签（`+N`）：固定中性色，不参与彩色映射
- 第三行（有标签）：最近消息，单行省略
- 第二至三行（无标签，默认）：最近消息，双行省略
- 第二至三行（无标签，条件命中）：展示最近两条可渲染消息，第二行=最近一条、第三行=倒数第二条，均单行省略
- 条件命中规则：最近一条消息经实际渲染宽度测量不足一行，且最近两条可渲染消息来自同一发送方（均为自己或均为对方）
- 摘要：不显示 CHAT_INFO 或输入状态消息
- 未读提示：显示未读数；手动标记未读时显示“+”，位置固定在内容区第三行末尾
- 当列表已存在至少 1 位联系人时，列表末尾展示联系人上限提示区：
  - 若 `GET /api/v1/contacts/limit` 返回 `available_total > 0`：展示“还可以再添加 X 位联系人”，并提供“去添加”入口跳转发现页
  - 若 `available_total = 0`：展示“联系人已达上限，先和他们聊聊吧”，并提供“邀请朋友加入增加联系人上限”入口跳转邀请好友页
  - 若联系人上限接口请求失败或未返回有效 `available_total`：隐藏该提示区
  - 其中 `X` 直接取 `available_total`，不使用本地联系人数量推算

### 列表操作

- 点击进入对话页面
- 滑动或菜单操作：标为未读/已读、联系人详情

### 未读规则

- 未读状态仅在客户端管理，与服务端 ACK 无关
- 实时消息与离线消息共用同一未读逻辑
- 进入会话页即清零该会话未读
- TYPING/NOTIFICATION/CHAT_INFO 不计入未读
- “标为未读”为客户端本地操作

### 离线补偿与 ACK

- 离线补偿与 ACK 规则见：`../../message/delivery-reliability.md` 与 `../../../api/messages-offline.md`。

## 对话页面

### 顶栏

- 返回按钮
- 显示备注或昵称（备注优先）
- 输入状态显示“对方正在输入…”
- 更多按钮进入聊天详情

### 聊天区域

- 日期分隔：小号字体，水平居中
- chat_info：样式同日期分隔
- 对方气泡：灰色系
- 自己气泡：产品主色
- 进入会话时滚动位置处理：
  - 若存在历史滚动位置且不在底部，恢复到上次位置
  - 否则定位到列表底部
- 滚动位置为客户端本地状态
- 清空聊天记录或删除联系人时清除该会话的滚动状态

### 输入区域

- 表情按钮与表情面板
- 输入框：
  - 从空白开始输入触发 typing_start（发送前 1 秒 buffer）
  - 输入清空且输入法结束时触发 typing_end（立即发送）
  - 字符上限由配置控制；小程序当前固定 49（见 `../mini-program/prototype.md`）
- 发送按钮：发送文本消息
- 键盘确认发送与发送按钮发送后，键盘保持打开

### 消息状态

- 发送中：显示加载态
- 发送成功：正常展示
- 发送失败：显示红色感叹号，支持重试

## 聊天详情页

### 联系人信息

- 头像、名称、标签
- 查看资料（进入联系人资料页）

### 聊天设置

- 清空聊天记录（仅清空本地消息，保留联系人）
- 删除联系人（解除关系并清空聊天记录）

## 个人资料页（联系人）

### 数据来源

### 展示字段

- 头像、昵称、性别、个性签名、地区、标签

### 操作

- 编辑备注
- 编辑描述
- 管理标签
