# 联系人与聊天

本规范定义联系人列表、对话页面与聊天设置的通用行为。

## 联系人列表（聊天列表）

### 数据来源

- [联系人列表接口](../../../api/contacts.md#获取联系人列表)

### 排序规则

- 置顶联系人优先
- 其余按最后消息时间倒序

### 列表项展示

- 头像：显示联系人头像（如未设置则由后端返回默认头像）
- 名称：备注优先，否则昵称；为空则保持空白
- 日期：最近一条消息时间
- 摘要：不显示 CHAT_INFO 或输入状态消息
- 标签：显示在名称右侧
- 未读提示：按免打扰设置显示红点或未读数

### 列表操作

- 点击进入对话页面
- 滑动或菜单操作：标为未读、删除联系人

### 未读规则

- 未读状态仅在客户端管理，与服务端 ACK 无关
- 实时消息与离线消息共用同一未读逻辑
- 进入会话页即清零该会话未读
- TYPING/NOTIFICATION/CHAT_INFO 不计入未读
- “标为未读”为客户端本地操作

### 离线补偿与 ACK

- 断线重连后必须先拉取离线消息，再允许发送 ACK
- 实时消息到达时先落盘与展示，补偿完成前不得 ACK
- ACK 必须基于客户端已持久化的最大 (sent_time, msg_id_server)

## 对话页面

### 顶栏

- 返回按钮
- 显示备注或昵称（备注优先）
- 输入状态显示“对方正在输入…”
- 更多按钮进入聊天详情

### 聊天区域

- 日期分隔：小号字体，水平居中
- chat_info：样式同日期分隔
- 对方气泡：灰色系
- 自己气泡：产品主色
- 进入会话时滚动位置处理：
  - 若存在历史滚动位置且不在底部，恢复到上次位置
  - 否则定位到列表底部
- 滚动位置为客户端本地状态
- 清空聊天记录或删除联系人时清除该会话的滚动状态

### 输入区域

- 表情按钮与表情面板
- 输入框：
  - 从空白开始输入触发 typing_start
  - 输入清空且输入法结束时触发 typing_end
  - 字符上限由配置控制；小程序 MVP 固定 49（见 `../mini-program/prototype.md`）
- 发送按钮：发送文本消息

### 消息状态

- 发送中：显示加载态
- 发送成功：正常展示
- 发送失败：显示红色感叹号，支持重试

## 聊天详情页

### 联系人信息

- 头像、名称、标签
- 查看资料（进入联系人资料页）

### 聊天设置

- 置顶聊天
- 消息免打扰
- 清空聊天记录（仅清空本地消息，保留联系人）
- 删除联系人（解除关系并清空聊天记录）

## 个人资料页（联系人）

### 数据来源

- [联系人详情接口](../../../api/contacts.md#获取单个联系人详情)

### 展示字段

- 头像、昵称、性别、个人简介、地区、标签

### 操作

- 发送消息（进入对话）
- 编辑备注
- 管理标签
