# 发现页

本规范定义发现页的通用交互与展示规则。

## 数据来源

- [广场推荐接口](../../../api/discovery.md#获取广场随机联系人)

## 入口页

- 入口页提供分类卡片：`pages/square-entry/square-entry`
- 点击卡片进入 Square 列表页，并携带 `category` 参数

## 筛选栏

- Square 列表页提供分类切换
- 默认分类：交友
- 分类示例：交友/恋爱/倾诉/闺蜜/同好

## 刷新规则

- 遵守刷新频率限制（超限提示且保持当前数据）

## 结果展示

- 头像、昵称、性别、标签、地区
- 后端返回为空时不设置默认值

## 添加联系人

- 使用 [联系人申请接口](../../../api/contact-requests.md#发送联系人申请)
- 统一返回“请求已发送”
