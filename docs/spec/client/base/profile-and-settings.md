# 我的与设置

本规范定义个人中心与设置页的通用展示。

## 我的（个人中心）

- 个人资料缩略：头像、昵称、敲敲号
- 账号与安全：手机号展示、重新绑定入口、退出登录
- 关于：版本号、版权信息

## 账号与安全

- 手机号：显示脱敏手机号
- 重新绑定：由各端登录链路实现
- 退出登录：确认后退出并返回登录页

## 关于

- 应用图标与名称
- 版本号
- 法律信息与版权信息（如有）

## 个人资料页（自己）

- [用户资料接口](../../../api/user.md#获取用户资料)
- [更新资料接口](../../../api/user.md#更新用户资料)

字段：头像、昵称、性别、个人简介、地区、账号信息
