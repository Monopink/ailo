# 我的与设置

本规范定义个人中心与设置页的通用展示。

## 我的（个人中心）

- 个人资料缩略：头像、昵称、敲敲号
- 菜单分组：
  - 第一组：我的资料、账号与安全
  - 第二组：填写邀请码、邀请得联系人上限
  - 第三组：关于
- 页面加载时调用 `GET /api/v1/invitations/binding-status`。
- 使用邀请码绑定状态服务维护 `bound/unbound/unknown` 状态（TTL + dirty + in-flight 去重）。
- 当 `is_bound=true`（状态为 `bound`）时，隐藏“填写邀请码”入口；请求失败时保留上次状态，若无历史状态则按 `unknown` 展示入口。
- 邀请入口文案固定为“邀请得联系人上限”

## 账号与安全

- 手机号：独立卡片展示脱敏手机号
- 重新绑定：由各端登录链路实现
- 青少年模式：独立卡片提供入口，显示当前开启/关闭状态
- 退出登录：确认后退出并返回登录页

## 青少年模式

- 入口：`pages/account-security/account-security` -> `pages/minor-mode/minor-mode`
- PIN 规则：固定 4 位数字
- 未开启流程：
  - 介绍页（展示保护内容）
  - 点击「开启青少年模式」后进入密码设置页
  - 输入 4 位 PIN 并确认，二次输入一致后调用开启接口
  - 开启成功提示后返回账号与安全页
- 已开启流程：
  - 介绍页底部主按钮为「关闭青少年模式」
  - 点击后进入 PIN 校验页
  - 校验通过后调用关闭接口
  - 关闭成功提示后返回账号与安全页
- 修改密码流程（仅已开启时可见）：
  - 在介绍页点击「修改青少年模式密码」
  - 先校验旧 PIN，再设置新 PIN，并进行二次确认
  - 修改成功后停留在青少年模式页
- 客户端本地错误次数限制：连续失败达到上限后临时锁定输入

## 关于

- 用户协议入口（`page_key=user_agreement`）
- 隐私政策入口（`page_key=privacy_policy`）
- 联系我们入口（公众号关注引导）：
  - 主链路：点击后调用 `wx.openOfficialAccountProfile({ username })` 打开公众号主页。
  - 降级链路：当主链路不可用或调用失败时，展示公众号二维码（支持长按识别）与“复制公众号用户名”按钮。
- 版权信息

## 个人资料页（自己）

- [用户资料接口](../../../api/user.md#获取用户资料)
- [更新资料接口](../../../api/user.md#更新用户资料)

字段：头像、昵称、性别、个性签名、地区、账号信息

- 敲敲号未设置时：显示“设置敲敲号”入口。
- 敲敲号设置流程：输入后点击“确认”，先调用 `GET /api/v1/user/username/check` 校验；校验通过后弹出二次确认，再提交 `PUT /api/v1/user/profile`。
- 敲敲号已设置时：隐藏编辑入口，仅展示当前敲敲号。
- 个性签名支持清空提交；提交空内容时写入 `null`（即清空）。

## 地区

### 字段语义

- 地区为用户资料的可选字段，用于资料展示与 AI 背景信息。
- 地区按“国家/地区 +（中国大陆）市级区划代码”结构化存储，展示使用 `region` 字段快照。

### 编辑交互

- 个人资料页点击地区字段后，直接打开地区选择器。
- 用户确认省市后，客户端直接调用 `PUT /api/v1/user/profile` 提交地区更新。

### 选择口径

- 地区当前仅支持中国大陆（`CN`）。
- 用户选择省与市，不选择区县。

### 写入口径

- 客户端提交 `region_country_code`、`region_cn_city_code`、`region_province_name`、`region_city_name`。
- `region` 由后端根据提交的省名与市名按展示规范生成，客户端不提交 `region`。
- 清空地区时，以上四个字段同时提交 `null`。

### 展示规范（`region`）

- 当国家/地区为 `CN`：`region` 按 `"{省名} {市名}"` 展示（中间使用单个空格），且省名与市名均不包含行政区划后缀：
  - 省级后缀：不包含“省”“市”“自治区”“特别行政区”及民族自治后缀（例如“内蒙古自治区”展示为“内蒙古”）。
  - 市级后缀：不包含“市”“地区”“盟”“自治州”及民族自治后缀。
  - 直辖市：当省名与市名一致时，`region` 仅展示省名（例如“北京”）。
- 未设置地区时：地区字段展示为空（不展示占位地区文案）。
