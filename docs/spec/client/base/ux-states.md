# 通用状态与体验

本规范定义客户端通用状态与体验优化规则。

## 网络与加载状态

- 连接中断：顶栏显示“正在连接…”
- 重连成功：恢复正常状态
- 首次加载：显示加载动画
- 下拉刷新：支持刷新联系人列表与消息
- 上滑加载：聊天记录分页加载

## 错误处理

- 网络超时：提示超时并允许重试
- 服务异常：显示友好提示，避免暴露技术细节
- 输入超长：禁用发送并提示字符数（允许前端限制小于服务端）

## 空状态

- 无联系人：显示引导添加联系人
- 无消息：展示欢迎或使用提示
- 加载失败：展示重试入口
- 非空联系人列表：在列表底部展示联系人上限提示与动作入口（规则见 `contacts-and-chat.md`）

## 体验优化

- 图片懒加载
- 操作反馈（触觉/视觉）
- 删除等危险操作需二次确认
- 客户端缓存联系人信息与聊天记录
