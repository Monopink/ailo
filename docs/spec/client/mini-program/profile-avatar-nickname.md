# 小程序头像昵称填写

本规范定义微信小程序端资料编辑中的头像与昵称填写能力。

## 适用页面

- `setup`
- `profile-detail`
- `field-edit`（仅 `domain=profile && field=nickname`）

## 头像填写

### Setup

- 头像区域为单一入口。
- 基础库 `2.21.2` 及以上，头像区域使用微信 `chooseAvatar` 能力。
- 基础库低于 `2.21.2`，头像区域点击后进入相册/拍照选择。

### Profile Detail

- 头像区域为单一入口。
- 基础库 `2.21.2` 及以上，头像区域使用微信 `chooseAvatar` 能力。
- 基础库低于 `2.21.2`，头像区域点击后进入相册/拍照选择。

### 上传流程

- `chooseAvatar` 返回的临时文件在当前页面直接导出为 `512x512 WebP` 后上传。
- 相册/拍照返回的临时文件进入 `avatar-cropper` 完成交互裁剪后上传。
- 上传链路规范见 `avatar-upload.md`。

## 昵称填写

### Setup

- 昵称输入框使用微信昵称填写能力。
- 提交时从表单当前值读取昵称。

### Field Edit

- 仅资料昵称编辑场景使用微信昵称填写能力。
- 其他字段保持现有输入方式。
- 提交时从表单当前值读取昵称。

### Profile Detail

- 昵称编辑入口保持现有跳转路径。
- 微信昵称填写能力由昵称输入页承接。

## 提交方式

- 使用微信昵称填写能力的场景采用 `form` 提交。
- 提交按钮使用原生 `button` 的 `form-type="submit"`。
- 页面实时展示仍可使用输入事件更新本地状态。

## 审核与提示

- 基础库 `2.24.4` 及以上，昵称输入框失焦后由微信执行异步安全审核。
- 昵称提交以表单当前值为准。
- 基础库 `2.29.1` 及以上可监听昵称审核结果，并使用轻提示反馈审核失败。

## 基础库兼容

- 基础库 `2.21.2` 起支持微信头像与昵称填写能力。
- 基础库低于 `2.21.2` 时，头像回退为相册/拍照入口，昵称回退为普通文本输入。
- 低版本回退为静默行为，不额外提示升级。
