# 小程序原型文档

小程序功能应该精简，聚焦核心功能：聊天、发现联系人、添加联系人。

## 图标设计规范

### 图标方案

**页面内图标**：使用 iconfont（阿里巴巴矢量图标库）

- 矢量图标，任意缩放不失真
- 通过 CSS `color` 属性控制颜色
- 使用 class 名称显示图标（如 `<text class="iconfont icon-send"></text>`）

**tabBar 图标**：使用 PNG 图片（小程序限制）

- 尺寸：81px × 81px（推荐）
- 格式：PNG，支持透明背景
- 需要两套：默认状态 + 选中状态

### 需要的图标

**对话页面**：

- `icon-send` - 发送按钮（圆形按钮内的向上箭头）
- `icon-smile` - 表情按钮（笑脸）
- `icon-keyboard` - 键盘按钮（表情键盘打开时显示）
- `icon-warning` - 消息发送失败图标（红色感叹号）

**底部导航栏（tabBar）**：

- 聊天 - 默认状态 + 选中状态
- 发现 - 默认状态 + 选中状态
- 我的 - 默认状态 + 选中状态

**其他页面**：

- `icon-back` - 返回按钮
- `icon-more` - 更多按钮
- 其他根据开发需要补充

### 实施说明

1. 从 iconfont.cn 创建项目并选择图标
2. 下载字体文件（.ttf）到 `assets/fonts/` 目录
3. 创建 `styles/iconfont.wxss` 样式文件
4. 在 `app.wxss` 中引入：`@import "styles/iconfont.wxss";`
5. 代码中已预留图标位置，使用 TODO 注释标记

## 页面

### 欢迎页（未登录）

- 作为未登录状态的入口页面，展示品牌与“开始使用/登录”等操作。
- 不展示底部 tabBar（聊天/发现/我的）。
- 点击操作进入登录页（微信授权或手机号登录）。
- 未登录状态下不允许访问聊天、发现、我的等 tab 页。
- 陌生人详情页（`pages/stranger-info`）为公开页面，可通过分享/外链直达；但从应用内部导航到该页通常发生在登录后（从发现页进入）。

### 注册登录页

#### 微信登录流程

**流程说明**:

1. 用户点击【微信登录】按钮
2. 调用wx.login()获取login_code
3. 显示【获取手机号】按钮
4. 用户点击【获取手机号】按钮
5. 用户授权后获取phone_code
6. 调用统一认证接口（详见 [微信登录](../api/auth.md#微信登录)）
7. 后端返回结果:
   - 如果是+86手机号: 直接登录成功
   - 如果是国际手机号: 显示手机号绑定页面
8. 登录成功后检查用户资料,如果nickname为NULL则强制跳转资料设置页面

**微信授权页面**:

- 【微信登录】按钮
- 点击后调用wx.login()获取login_code
- 显示【获取手机号】按钮
- 用户点击【获取手机号】按钮(`<button open-type="getPhoneNumber">`)
- 用户授权后bindgetphonenumber事件返回phone_code
- 通过 [微信登录](../api/auth.md#微信登录) 接口向后端提交 `login_code` 与 `phone_code`
- 请求参数: {login_code, phone_code}

**手机号绑定页面(回退方案)**:

- 使用场景:
  1. 微信获取手机号接口失败
  2. 微信返回国际手机号(非+86)
- 【国家代码】固定显示+86,不可选择
- 【手机号输入框】输入11位手机号(不含国家代码)
- 【获取验证码】按钮,60秒倒计时
- 【验证码输入框】输入6位验证码
- 【确认绑定】按钮
- 调用 [手机号验证](../api/auth.md#手机号验证) 接口完成绑定
- 请求参数格式以 API 文档为准（统一使用 +8613800138000）

**资料设置页面**:

- 当用户nickname为NULL时强制显示,不能跳过
- 【头像】显示默认头像,点击弹出选择框,从内置的默认头像中选择
  - 头像格式: assets://1234, assets://2345等
  - 小程序内置6-12个默认头像
- 【昵称】必填,最大长度由环境变量控制
- 【性别】男、女、其他。必填
- 【个人简介】可选,最大长度由环境变量控制
- 【地区】可选,前端维护地区列表
- 【完成】按钮,点击后通过 [完成注册接口](../api/auth.md#完成注册) 提交资料,成功后跳转主界面

**错误处理**:

- 微信授权失败: 显示错误提示,提供重试按钮
- 手机号绑定失败: 显示具体错误信息(验证码错误、手机号已注册等)
- 资料设置失败: 显示错误提示,不允许跳过

**注意事项**:

- 强制绑定手机号,不能跳过
- MVP阶段只支持+86(中国大陆)手机号
- 一个手机号只能绑定一个账号
- 如果手机号已注册,通过手机号关联账号
- 资料设置页面根据nickname是否为NULL判断是否需要显示
- 手机号存储格式: E.164标准格式(+8613800138000)
- 手机号显示格式: +86 138******00(脱敏)

### 主界面底部导航栏（登录后）

【聊天】主界面默认页面，点击进入聊天页。

【发现】点击进入发现页。

【我的】点击进入我的页。

说明：未登录状态不展示 tabBar，由 `app.js` 的统一鉴权逻辑重定向至欢迎/登录。

### 聊天列表（联系人列表）

聊天列表即联系人列表，展示所有联系人及其最近消息。通过 [联系人列表接口](../api/contacts.md#获取联系人列表) 获取数据。

#### 顶栏

【信息区域】默认情况为「敲敲(3)」显示品牌名（来自环境变量），括号展示未读消息数量，最高为99+，如果为0则不显示。

网络、服务异常时显示「正在连接…」。

加载内容时显示「正在加载…」。

#### 联系人列表

联系人列表按照最后消息的日期顺序排列。置顶的联系人显示在最前，并且按照日期顺序排列。

点击联系人进入对话页面，点击菜单按钮出现菜单。

【头像】显示用户设置的头像,如果头像未设置则使用默认头像(default)。

【名称】备注或nickname，备注优先。如果为空则显示空白，不要设置默认值。

【日期】最近的一条消息的日期。

【最近的一条消息缩略】不包括chat_info或输入状态消息。

【标签】显示在名称右侧，标签形式。

【消息圆点/消息数量红点】根据「消息免打扰」设置决定显示圆点还是消息数量。

【菜单按钮】右菜单选项：标为未读、删除联系人。点击标为未读可以增加消息圆点。点击删除联系人选项扩大文字变为：确认删除。点击确认删除通过 [删除联系人接口](../api/contacts.md#删除联系人) 解除联系人关系并清空聊天记录。

#### 联系人操作

- 资料：查看联系人详细资料（通过 [联系人详情接口](../api/contacts.md#获取单个联系人详情)）
- 发送消息：直接进入对话页面
- 编辑备注：修改联系人备注名称（通过 [更新联系人接口](../api/contacts.md#更新联系人信息)）
- 删除联系人：解除联系人关系，清空聊天记录（通过 [删除联系人接口](../api/contacts.md#删除联系人)）

【交友】

【恋爱（限时免费）】

【倾诉（限时免费）】

【闺蜜（限时免费）】

【同好（限时免费）】

默认为交友。

大按钮，每个按钮都有图案装饰，默认展开。点击后收起，上滑收起。

#### 功能栏

【刷新按钮】遵守刷新频率限制（超限返回提示，保持当前数据）。

#### 结果栏

展示符合筛选条件的联系人结果

【头像】

【nickname】

【性别】

【标签】添加后自动添加到联系人的标签中。

【添加】发送联系人申请（统一使用 [联系人申请接口](../api/contact-requests.md#发送联系人申请)，统一返回"请求已发送"）。

后端返回为空时均不设置默认值。

### 我的

【个人资料缩略】头像、昵称。点击进入个人资料页（通过 [用户资料接口](../api/user.md#获取用户资料) 获取数据）。

【会员等级】点击进入会员页面（2.0功能）。

【退出登录】点击退出当前账户（通过 [退出登录接口](../api/auth.md#退出登录)）。

### 对话页面

#### 顶栏

【<】后退按钮。

【信息区域】正常情况备注或nickname，备注优先。如果为空则显示空白，不要设置默认值。

#### 聊天区域

【日期】小号字体，水平居中。

【chat_info消息】样式和日期一致。

【对方头像和气泡】气泡为无颜色灰度和背景区分。

【自己的头像和气泡】气泡为绿色（产品主色调）。

输入状态显示。

#### 输入区域

【表情按钮】点击出现表情选择，表情选择框对表情进行分组展示。

表情包括emoji字符、自定义emoji。点击emoji分组的表情加入到输入框。

【输入框】输入框从空白输入内容后（包括输入法的开始输入状态）发送开始输入的状态，输入框从有内容删除所有内容（且输入法的没有输入状态）发送结束输入状态。输入框字符上限为 49（MVP 固定）。

【发送按钮】点击发送内容。

- 查看资料：点击进入联系人资料页面

显示和编辑用户个人资料，对应profiles表数据。通过 [用户资料接口](../api/user.md#获取用户资料) 获取数据，通过 [更新用户资料接口](../api/user.md#更新用户资料) 提交修改。

#### 基本信息

- 头像：显示当前头像，点击可从预设头像中选择更换
  - 显示预设头像选择器
  - 头像相关的API和调用方式参考 [用户资料接口文档](../api/user.md)
- 昵称：显示和编辑用户昵称
- 性别：显示和编辑性别（男、女、其他）
- 个人简介：显示和编辑个人简介
- 地区：显示和编辑所在地区

#### 账户信息

- 敲敲账号：显示用户的username(默认为qiao_id)，通过 [账户信息接口](../api/user.md#获取账户信息) 获取
- 手机号：显示绑定的手机号（脱敏），点击可修改
  - 修改流程：验证当前手机号 → 输入新手机号 → 验证新手机号 → 更新
  - 调用接口：参考 [账户安全接口文档](../api/account-security.md)

## 交互细节和状态处理

### 消息状态管理

#### 消息发送状态

- 发送中：消息气泡显示发送中状态（转圈图标）
- 发送成功：正常显示消息内容
- 发送失败：消息气泡旁显示红色感叹号，点击可重试
- 失败原因：点击感叹号显示具体失败原因（网络错误、内容违规等）

#### 消息接收状态

- 正在输入：收到typing类型消息时显示"对方正在输入..."，持续10秒
- 输入结束：收到新消息或typing_end消息时取消输入状态

### 网络状态处理

#### 网络异常

- 连接中断：顶栏显示"正在连接..."
- 重连成功：自动恢复正常状态
- 长时间断网：显示网络错误提示，提供重试按钮

#### 数据加载

- 首次加载：显示加载动画
- 下拉刷新：支持下拉刷新联系人列表和消息
- 加载更多：聊天记录支持上滑加载历史消息

### 错误处理

#### 用户操作错误

- 输入超长：输入框达到字符限制时禁用发送，显示字符计数
- 网络超时：显示超时提示，提供重试选项
- 服务异常：显示友好的错误提示，避免暴露技术细节

#### 数据异常

- 空状态：无联系人时显示引导添加联系人
- 无消息：新对话显示欢迎消息或使用提示
- 加载失败：显示重试按钮，支持手动刷新

### 用户体验优化

#### 界面反馈

- 按钮点击：提供触觉反馈和视觉反馈
- 操作确认：删除等危险操作需要二次确认
- 状态提示：重要操作完成后显示成功提示

#### 性能优化

- 图片懒加载：头像和图片消息支持懒加载
- 消息分页：聊天记录分页加载，避免一次加载过多
- 缓存机制：联系人信息和聊天记录支持本地缓存

### 安全和隐私

#### 内容安全

- 隐私保护：用户数据加密传输和存储

#### 账户安全

- 登录验证：支持手机验证码登录
- 会话管理：支持踢出其他设备（2.0功能）
