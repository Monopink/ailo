# Username Rules

本文档定义 username 的服务端约束与判定规则。客户端可做同规则校验，但以服务端判定为准。

## 字段属性

- 表：`users`
- 字段：`users.username`
- 允许为 NULL；但只要提供值，就必须满足以下规则。

## 约束分层（单一规则源）

- 应用层（唯一规则源）：负责完整校验（格式、连续分隔符、保留字）。
- 数据库层（保底约束）：只负责 NULL/长度/唯一，不重复实现复杂正则。
- 当应用层规则升级时，优先更新本文件与服务端实现，避免多处规则漂移。

## 格式规则

- 长度：5~20
- 字符集：仅允许字母、数字、`_`、`-`
- 首字符：必须是字母
- 禁止连续分隔符：不允许出现 `__`、`--`、`_-`、`-_`

正则（等价表达）：

```txt
^(?!.*[_-]{2})[A-Za-z][A-Za-z0-9_-]{4,19}$
```

## 唯一性规则（大小写不敏感）

- 唯一性按小写判定（case-insensitive unique）。
- 数据库存储保留用户输入的原始大小写。

判定逻辑：

```txt
LOWER(username) 全局唯一
```

## 保留字规则

- 保留字禁止使用。
- 保留字配置项：`system_configs.username_reserved_words`
  - 类型：JSON 数组
  - 约束：配置内容必须为全小写
- 判定方式：将输入 username 转为小写后与保留字列表比较。
